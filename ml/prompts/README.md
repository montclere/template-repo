# Промпты

Каждый промпт — отдельный файл `<назначение>.md`. Код загружает его через `load_prompt("<назначение>")` из `app/llm/prompts.py`, в коде промптов нет.

- `ask.md` — системный промпт примера `/api/v1/ask`.
- `judge.md` — промпт модели-судьи для `make eval`.

Правка промпта видна в git отдельным изменением: её можно откатить и связать с результатом `make eval`.
