## 7. Задачи

5–8 задач. Каждая даёт что-то работающее от экрана до ответа и закрывает хотя бы один критерий. Первая — скелет на заглушках.

- [ ] **T1. Скелет.** <что сделать>. Критерий: K1. Готово, когда: <проверяемое условие>
- [ ] **T2.** … Критерий: … Готово, когда: …
- [ ] **V1. Ревью по критериям.** После половины задач. Агент ставит каждому критерию оценку 1–5 по текущему состоянию и предлагает до трёх улучшений. Код не пишется, решение за человеком.
- [ ] **T3.** … Критерий: … Готово, когда: …
- [ ] **V2. Ревью перед показом.** То же самое плюс прогон сценария демо.

Шаги задачи агент расписывает под ней прямо перед началом работы, по частям:

```
- [ ] **T2. Ответ со ссылкой на источник.** Критерий: K1. Готово, когда: …
  - [ ] контракт: поле `sources` в `AskResponse` (ml) и `QuestionRead` (backend)
  - [ ] ml: промпт и разбор ответа модели
  - [ ] backend: сохранить и вернуть поле
  - [ ] frontend: показать ссылку под ответом
  - [ ] проверка: 2 случая в evals, `make check`, `make smoke`, `make eval`
```

Тип «разведка» (без тестов, результат — вывод в `PROGRESS.md`):

- [ ] **R1.** <что выяснить>
