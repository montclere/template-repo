# Входные материалы

Сюда кладётся всё, что есть на старте, как есть:

- описание хакатона или задачи от организаторов;
- критерии оценки жюри;
- идея решения;
- данные, примеры, ссылки на API и другие материалы.

Формат — MD или обычный текст. Имена и количество файлов не важны.

- Агент эти файлы не правит. Это оригиналы, с которыми сверяется бриф.
- Вопросы агент задаёт только по пробелам и противоречиям, не больше пяти.
- Если критериев жюри нет, задачи выводятся из сценария демо.
