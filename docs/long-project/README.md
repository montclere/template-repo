# Шаблоны для долгого проекта

Нужны только если проект длиннее трёх дней. На хакатоне хватает `docs/BRIEF.md`.

Скопируйте три файла в `docs/` и работайте с ними вместо брифа:

- `SPEC.md` — что строим и зачем, требования с номерами.
- `PLAN.md` — как строим: стек, схема, контракты, этапы, принятые решения.
- `TASKS.md` — задачи по этапам.

Для долгого проекта также стоит добавить миграции базы (Alembic) и тесты фронтенда: в каркасе их нет намеренно.
