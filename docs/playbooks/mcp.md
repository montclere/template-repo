Проверено: 2026-11-14. Версия спецификации на эту дату: **2026-07-28**. Версию SDK впиши сюда при установке: <…>.

Спецификация и SDK меняются быстро. Перед началом работы сверь эту страницу с актуальной документацией через Context7.

## Что важно в версии 2026-07-28

- Протокол без состояния: сессий и стартового рукопожатия на уровне протокола нет. Состояние между вызовами передавай явно, идентификатором, который вернул инструмент.
- Транспорт для удалённого сервера — Streamable HTTP. Старый HTTP+SSE устарел, новый код на нём не пишется.
- Для локального запуска — stdio.

## Как строить

- Сервер создаётся в `ml/app/mcp/` только когда он нужен проекту. Это тонкая обёртка: логика лежит в соседних модулях `ml/app/`.
- Инструменты проектируются по `agents.md`: мало, с описаниями для модели, с короткими ответами. Длинные списки отдаются постранично.
- Вход каждого инструмента валидируется по схеме.

## Проверка

5–10 реалистичных вопросов, на которые агент должен ответить, пользуясь только этим сервером. Они записываются в `ml/evals/cases.jsonl` с типом `tool`.

## Подключение к агентам

`.mcp.json` в корне читает Claude Code. Для Codex и Cursor тот же сервер добавляется в их собственные конфиги вручную.
