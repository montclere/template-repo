# Агенты

Проверено: 2026-11-14. Перед хакатоном перепроверить.

Здесь варианты по умолчанию. Если задаче подходит другое, делай другое и запиши причину в `PROGRESS.md`.

## С чего начинать

1. Один вызов модели с хорошим промптом.
2. Фиксированный сценарий из нескольких шагов.
3. Агент, который сам выбирает инструменты в цикле.

Переходи на следующую ступень, только когда предыдущая не проходит эвалы. Агент дороже, медленнее и хуже отлаживается.

## Инструменты

- Мало инструментов, каждый делает одно законченное действие.
- Название и описание пишутся для модели: когда вызывать и что вернётся.
- Вход описан схемой. Ошибка возвращается текстом, по которому модель поймёт, что исправить.
- Ответ инструмента короткий: только нужное для следующего шага.

## Контекст

- Вывод модели, который читает код, запрашивай в структурированном виде по схеме.
- Длинную историю не тащи целиком: сжимай или веди заметки в файле.
- Субагент оправдан, когда подзадача читает много, а вернуть нужно мало.

## Границы

- У цикла агента есть предел шагов и предел стоимости.
- Действия, которые нельзя отменить (отправка, оплата, удаление), подтверждает человек.
- Все вызовы модели идут через `ml/app/llm/client.py` и пишутся в `ml/logs/llm.log.jsonl`.
